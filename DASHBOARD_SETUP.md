# Dashboard Setup Guide

## Overview
This guide explains how to update the Vercel dashboard with live data from your research pipeline.

## Current State
- **Backend**: Python pipeline in `trg_workbench/` fetches real market data, SEC filings, and macro data
- **Frontend**: `index.html` is deployed to Vercel at https://sellside-research-engine.vercel.app/
- **Problem**: Frontend was showing hardcoded mock data, not connected to backend

## Solution Implemented

### 1. New Export Script: `export_dashboard_data.py`
This script:
- Runs the v2 pipeline to fetch latest data
- Transforms it into the JSON format expected by `index.html`
- Outputs `dashboard_data.json` for deployment

### 2. Updated Frontend: `index.html`
Modified to:
- Fetch `dashboard_data.json` on load (instead of using hardcoded data)
- Show loading state while fetching
- Display error message if data fetch fails
- Auto-select first available ticker if AAPL doesn't exist

## Usage

### Option A: Manual Update (Before Each Deploy)

```bash
# 1. Run the export script with desired date
python export_dashboard_data.py --as-of 2026-05-31

# 2. Verify the output
cat dashboard_data.json | head -50

# 3. Commit and push to trigger Vercel deploy
git add dashboard_data.json
git commit -m "Update dashboard data for 2026-05-31"
git push
```

### Option B: Using Existing Normalized Data (Skip Fetch)

If you already have normalized data files from a previous pipeline run:

```bash
# Skip API calls, use existing data/normalized/*.csv files
python export_dashboard_data.py --as-of 2026-04-12 --skip-fetch
```

### Option C: Automated Daily Updates (GitHub Actions)

Create `.github/workflows/update_dashboard.yml`:

```yaml
name: Update Dashboard Data
on:
  schedule:
    - cron: '0 6 * * 1-5'  # Weekdays at 6 AM UTC
  workflow_dispatch:      # Allow manual trigger

jobs:
  update:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      
      - name: Set up Python
        uses: actions/setup-python@v4
        with:
          python-version: '3.10'
      
      - name: Install dependencies
        run: pip install -r requirements.txt
      
      - name: Export dashboard data
        env:
          SEC_USER_AGENT: ${{ secrets.SEC_USER_AGENT }}
          OPENAI_API_KEY: ${{ secrets.OPENAI_API_KEY }}
        run: python export_dashboard_data.py --as-of $(date +%Y-%m-%d)
      
      - name: Commit and push if changed
        run: |
          git config user.name github-actions
          git config user.email github-actions@github.com
          git add dashboard_data.json
          git diff --cached --exit-code || git commit -m "Auto-update dashboard data [skip ci]"
          git push
```

## Troubleshooting

### Error: "Failed to Load Dashboard Data"
**Cause**: `dashboard_data.json` not found or not committed

**Fix**:
```bash
python export_dashboard_data.py --as-of 2026-05-31
git add dashboard_data.json
git commit -m "Add dashboard data"
git push
```

### Error: "No ticker data available"
**Cause**: Missing normalized data files

**Fix**: Run the full pipeline first:
```bash
python main_v2.py fetch-all --as-of 2026-05-31
python export_dashboard_data.py --as-of 2026-05-31
```

### Error: "SEC_USER_AGENT missing"
**Cause**: SEC requires user agent header

**Fix**: Set environment variable:
```bash
export SEC_USER_AGENT="Your Name your.email@example.com"
```
